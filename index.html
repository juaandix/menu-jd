          Google: turnos y Fitbit

          Conecta tu Google Calendar para que el botón de calendario de la pantalla Hoy proponga si ese día trabajas, buscando una palabra clave en el título de los eventos de ese día. Necesita conexión a internet; el resto de la app sigue funcionando sin ella.

          Con el mismo Client ID, los botones "Fitbit" de Hoy y Semana traen tus pasos (y tu peso, si lo registras en Google Health) desde la API de Google Health. En el proyecto de Google Cloud tienen que estar habilitada la "Google Health API" y los permisos googlehealth.activity_and_fitness.readonly y, para el peso, googlehealth.health_metrics_and_measurements.readonly. Para enviar tus comidas (botón de Hoy) hace falta además googlehealth.nutrition.writeonly.

          ¿Cómo consigo el Client ID? En Google Cloud Console: crea un proyecto → activa la API "Google Calendar API" → pantalla de consentimiento OAuth (tipo Externo, añádete como usuario de prueba) → Credenciales → "Crear credenciales" → "ID de cliente de OAuth" tipo Aplicación web → en "Orígenes de JavaScript autorizados" añade exactamente → copia el Client ID y pégalo arriba.
